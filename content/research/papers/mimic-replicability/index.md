两篇论文都在 MIMIC-III 上做自动编码，Micro-F1 相差几分。这几分可能来自模型，也可能来自病历截断长度、阈值和数据划分。Edin 等人先按旧协议重训已有模型，再用一套共同的流程比较。输入仍是出院小结，输出仍是一组 ICD 诊断和操作编码。论文改动的是训练和评估协议，借此检查此前的差距有多少能重现。

## 一、复核研究如何组织比较

MIMIC 是包含临床记录和编码的数据资源。这篇论文考察的自动编码任务，以出院小结为输入，以住院诊断和操作编码集合为目标。模型结构只是实验的一部分，数据如何划分、文字保留多少、怎样把分数变成标签，都会影响最后的指标。

复核分成两个步骤。先保留旧划分，检查已有结果和评估实现能否复现；再建立标签覆盖更合理的新划分，用共同的训练、调参和阈值选择规则重新比较模型。这样可以区分“原结果是否重现”和“统一条件下谁表现更好”，避免把两个问题混在一张榜单里。

Micro-F1 汇总所有标签的误报和漏报，常见编码对它影响较大。Macro-F1 按编码平均，更容易显现低频编码的表现，但必须先说明平均公式和哪些编码参加统计。

## 二、同一批预测为什么能算出两个 Macro-F1

旧实现有两处需要核对。第一处是平均顺序。有些代码先求所有标签的平均精确率 \(\bar P\) 与平均召回率 \(\bar R\)，再取二者的调和平均。论文改成先对每个标签分别计算 \(F_{1,\ell}\)，再取平均。可以用两个标签看出区别，其中一个只有高精确率，另一个只有高召回率。先求平均会把来自不同标签的长处合在一起，逐标签计算则会保留各自的短板。

第二处是参与平均的标签。旧版 MIMIC-III-full 的测试集中约 54% 的候选编码没有正例。若按逐标签平均、将缺失标签的 F1 记为 0，并让它们参加等权平均，有正例的标签即使全部预测正确，Macro-F1 也最多约为 46%。这个上限来自测试集覆盖与计分约定。

作者在旧划分上重算时，逐标签计算 F1，并将测试集中无正例的标签移出该项平均。表 4 的 LAAT 复核结果中，同一轮评估的旧口径 Macro-F1 是 8.2%，改后的口径为 16.2%，Micro-F1 为 56.1%。这个例子同时涉及公式和纳入规则，不能把变化全部归到其中一项。想复核自己的日志，至少要保留逐标签真值和预测，单张总分截图无法重算。

## 三、数据划分与统一比较协议

保留旧划分有助于对照以往论文。为了让稀有编码有机会出现在训练和测试数据中，作者另外从 MIMIC-III v1.4 构建 clean 划分，把总出现次数少于 10 的编码移出任务，扩大测试集并进行多标签分层采样。训练与测试患者互斥。MIMIC-IV v2.2 使用相近流程，分别形成 ICD-9 与 ICD-10 任务。

新划分共用训练策略与搜索流程，每个模型在自己的验证集上找使 Micro-F1 最大的决策阈值，然后固定阈值进测试集。学习率、dropout 和 batch size 等仍允许按模型调节，公平比较要求的是一致的选择规则。作者用十个随机种子报告结果，原文表 5 的部分均值如下，单位为百分比。

| 数据与编码体系 | LAAT Micro / Macro-F1 | PLM-ICD Micro / Macro-F1 |
| --- | ---: | ---: |
| MIMIC-III clean | 57.8 / 22.6 | 59.6 / 26.6 |
| MIMIC-IV ICD-9 | 61.7 / 26.4 | 62.6 / 29.8 |
| MIMIC-IV ICD-10 | 57.9 / 20.3 | 58.5 / 21.1 |

在 MIMIC-III clean 的阈值消融中，LAAT 的 Micro-F1 从 57.8 降到 56.2，Macro-F1 从 22.6 降到 19.0。一个没对齐的阈值选择就可能改变对模型差距的解释。另一组将输入截至 2,500 词，LAAT 和 PLM-ICD 的 Micro-F1 均下降约 0.2 个百分点。这个结果对应 2,500 词附近的对照，直接截到 512 token 或转向更长的病历时，还要重新检查被删掉的内容。 [原文表 5、6](https://arxiv.org/pdf/2304.10909)

## 四、低频编码与整份病历的正确率

作者在 MIMIC-IV ICD-10 上统计到，PLM-ICD 在所分析的 5,794 个诊断码中有 2,928 个从未正确预测，其中 110 个在训练集中已有超过 100 条样本。训练频率可以解释长尾的一部分，仍要逐类检查文本是否含有足够证据。论文的整份病历完全匹配率在这组设置为约 0.4%。即使排序指标较高，人工仍可能要加回漏掉的编码并移除误报。

clean 划分换来了更稳定的标签覆盖，同时排除了最稀有的编码，因此该协议测量的是筛选后标签集。跨医院或新的编码规范还需要独立数据。要比较两张结果表，先对齐出院小结的范围、ICD 版本、患者划分、无正例标签策略和验证集阈值，再把剩余差异放回模型结构和训练过程里解释。
