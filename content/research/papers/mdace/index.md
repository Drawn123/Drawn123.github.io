编码数据通常只告诉模型“一次住院有哪些编码”，没有指出这些编码分别由哪段文字支持。于是，一个模型即使预测正确，也可能高亮错误位置，而研究者缺少人工参考来评价它。

MDACE 为 MIMIC-III 的部分记录增加专业编码员标注的文本证据。有了这些标注，就能比较模型找出的文字与人工证据是否重叠。

## 一、一条证据记录包含什么

理解这份数据要区分三个单位。一次住院可以产生多份文书，一份文书可以包含多个编码的证据，一个编码也可能由几个不相邻的文本跨度支持。证据至少需要关联住院、具体文书、编码和文本位置，不能只保存一句脱离来源的短语。

例如，同一诊断在出院诊断和病程记录中各出现一次。两处文字可能都合理，但位置不同。评价模型时，要求找回同一位置，还是允许找到另一处同义证据，会得到不同结果。

完整数据包含住院编码 Inpatient 与专业服务编码 Profee 两种场景。它们遵循不同编码要求，不能仅因来自同一患者就认为标签应完全相同。

## 二、专业标注如何形成

作者从既有 MIMIC-III 编码测试集中抽取住院记录，收集可用文书，请编码员重新编码并标记依据。编码员主要按照 ICD-10 标注，再经通用等价映射 GEMs 和核对流程转为 ICD-9，以便已有模型使用。

两组标注采用不同目标。Inpatient 标出足够支持编码的证据，找到后可以不继续标记重复出现的表达。Profee 尽量完整地标记所有相关证据，因此耗时更长、覆盖住院记录更少。两者同时有场景和标注要求的差异，不能当成同一任务的“少量版”和“完整版”。

原文表 3 的规模如下。Profee 的编码和证据统计包含 CPT 操作术语体系。

| 统计单位 | Inpatient | Profee |
| --- | ---: | ---: |
| 住院记录 | 302 | 52 |
| 文书 | 604 | 588 |
| 编码种类数，ICD-9；Profee 含 CPT | 918 | 652 |
| ICD-9 证据跨度 | 3,934 | 5,563 |
| ICD-10 证据跨度 | 3,936 | 5,563 |

302 是住院记录数，604 才是该部分涉及的文书数。后续研究经常只取出院小结做实验，应当单独说明这个子集。原文表 4 显示，Inpatient 证据有 87.3% 位于出院小结，Profee 只有 28.5%，仅用小结会遗漏后者的大量证据。[数据统计与标注流程](https://aclanthology.org/2023.acl-long.416.pdf)

## 三、编码模型如何使用证据

作者在 EffectiveCAN 编码模型上建立多种证据提取基线。普通注意力模型只用文档编码标签训练，然后把注意力超过阈值的位置作为证据。有监督注意力还利用人工跨度，训练时引导注意力接近证据区域。线性或卷积标注头则学习对每个位置判断是否属于证据。

因此有两种监督对象。文档编码标签教模型“预测什么编码”，跨度标签教模型“从哪里找到依据”。给后者增加监督，不能假定前者必然同步提高，需要分别报告编码和证据指标。

证据数据原先来自旧编码测试集。若用其中部分记录训练证据模块，必须把相应记录移出编码测试集。论文建立了新的 Code+Evidence 划分；Inpatient 证据部分按 181、60、61 划分训练、验证和测试。数据隔离需要按记录身份检查，不能只看两个目录名称不同。

## 四、四种匹配指标各自衡量什么

| 指标 | 正确匹配的要求 | 能区分的错误 |
| --- | --- | --- |
| token 匹配 | 同一文档位置上的词或子词被选中 | 局部漏标、多选 |
| 完整跨度匹配 | 一整段连续证据的边界一致 | 只覆盖半个短语 |
| 位置无关 token 匹配 | 文本内容对应，允许位置不同 | 同一事实在别处再次出现 |
| 位置无关完整跨度匹配 | 完整短语对应，允许位置不同 | 同义证据位置差异与边界差异 |

位置无关匹配缓解了重复表达只标一次的问题，但也放松了位置要求。同一个疾病词在否定句和肯定句中意义不同，因此分数需要结合上下文解释。

原文表 9 在 Inpatient 出院小结测试集上报告，有监督注意力的 token F1 为 \(43.0\pm0.2\)，普通 EffectiveCAN 注意力为 \(36.2\pm0.6\)。换成位置无关 token 匹配，两者分别为 \(56.8\pm0.7\) 和 \(47.7\pm0.8\)，均为百分制。这说明监督与匹配口径都会影响结论。完整跨度匹配又更严格，有监督注意力 F1 为 \(27.8\pm0.6\)，不能用 token F1 代替它。

## 五、数据提供的依据与仍然缺少的依据

MDACE 使研究者可以检查高亮片段是否接近专业标注。但人工证据不是模型内部决策的记录，人工重叠高不等于归因忠实。充分标注也没有穷尽所有合理证据，低重叠可能包含位置差异或重复提及。

标注一致性经过共同复核后显著提高，不能把协商后的高一致性理解成编码员独立工作时没有分歧。原始 MIMIC 编码与重新标注编码存在差异，文书缺失和规范变化都可能参与其中。使用数据时，应保留文书范围、编码体系、映射版本及评价单位，避免把数据整理差异归因给模型。
