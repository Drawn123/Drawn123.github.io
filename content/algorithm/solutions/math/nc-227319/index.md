## NC227319 又一构造子序列

[又一构造子序列](https://ac.nowcoder.com/acm/problem/227319)

### 题意

给定整数 $n$，构造一个只包含小写字母、长度不超过 $10^5$ 的字符串，使其中恰好有 $n$ 个 `yyc` 子序列。

子序列不要求连续，但选择的字符必须保持原有顺序。即使选出的内容都是 `yyc`，只要选择的位置不同，也算不同的子序列。例如 `yyyc` 有 $3$ 个 `yyc` 子序列。

共有 $T$ 组数据，$1\le T\le10$，$1\le n\le10^9$。每组先输出字符串长度，再输出字符串；如果无解则输出 `-1`，有多种答案时输出任意一种即可。

### 思路

#### 从每个 c 的贡献出发

最直接的想法是在 `yy` 后面放 $n$ 个 `c`：

```text
yy + n 个 c
```

每个 `c` 前面都只有两个 `y`，因此各贡献 $1$ 个 `yyc`，总数确实是 $n$。但长度为 $n+2$，当 $n$ 较大时会超过限制。

要缩短字符串，可以让一个 `c` 对应更多个 `yyc`。

**如果一个 `c` 前面有 $k$ 个 `y`，从中任选两个，便能与这个 `c` 组成一个 `yyc`。** 所以这个 `c` 的贡献为：

$$
\binom{k}{2}=\frac{k(k-1)}2
$$

例如 `yyyyc`，最后一个 `c` 前面的四个 `y` 可以选出 $6$ 对，因此一共有 $6$ 个 `yyc`。

这里的公式只计算一个 `c` 的贡献。如果所有 `y` 都放在前面，每个 `c` 的贡献就完全相同，不一定能恰好凑出 $n$。我们需要利用 `c` 的位置，让不同的 `c` 产生不同的贡献。

#### 最后一个 c 贡献大部分，前面的 c 补差额

先只考虑最后一个 `c`，让它前面有尽可能多的 `y`，但贡献不能超过 $n$。也就是找到最大的整数 $k$，满足：

$$
\binom{k}{2}\le n
$$

最后一个 `c` 贡献 $\binom{k}{2}$，剩下的数量记作：

$$
rem=n-\binom{k}{2}
$$

剩下的 `rem` 个，可以用最开始的办法补：在最前面的两个 `y` 后面放 `rem` 个 `c`，让它们每个只贡献 $1$。

因此字符串按下面的顺序构造：

```text
yy + rem 个 c + (k-2) 个 y + 一个 c
```

例如 $n=8$，最多取 $k=4$，因为 $\binom42=6\le8$，而 $\binom52=10>8$。剩下 $rem=2$，构造为：

```text
yy cc yy c
```

上面的空格仅用于分组，实际输出为 `yyccyyc`。

1. 前面的两个 `c`，每个前面都只有两个 `y`，一共贡献 $2$。
2. 最后一个 `c`，前面一共有四个 `y`，贡献 $\binom42=6$。

对于一般的 $n$，前面的 `rem` 个 `c` 共贡献 `rem`，最后一个 `c` 贡献 $\binom{k}{2}$。后面补的 `y` 不能与前面的 `c` 组成 `yyc`，因为子序列必须保持原有顺序。因此总数恰好为：

$$
rem+\binom{k}{2}=n
$$

#### 为什么构造长度不会超过限制

因为 $k$ 是满足条件的最大整数，再增加一个 `y` 就会超过 $n$，所以：

$$
\binom{k}{2}\le n<\binom{k+1}{2}
$$

减去 $\binom{k}{2}$，得到：

$$
0\le rem<\binom{k+1}{2}-\binom{k}{2}=k
$$

也就是说，剩余数量满足 $rem\le k-1$。

构造中有 $k$ 个 `y` 和 $rem+1$ 个 `c`，因此长度满足：

$$
len=k+rem+1\le k+(k-1)+1=2k
$$

再看 $k$ 的范围。由于 $n\le10^9$，而：

$$
\binom{50000}{2}=1249975000>10^9
$$

所以 $k<50000$，于是：

$$
len\le2k<100000
$$

因此所有合法的 $n$ 都能构造出答案，不需要输出 `-1`。当 $n=1$ 时，$k=2$、$rem=0$，构造出的字符串就是 `yyc`。

**时间复杂度为 \(O(\sqrt n)\)**

### AC代码

```cpp
void solve(){
    int n;
    cin>>n;
    int k=2;
    while(k*(k+1)/2<=n) k++;
    
    int rem=n-k*(k-1)/2;
    string ans="yy";
    for(int i=0;i<rem;i++){
        ans += 'c';
    }
    for(int i=0;i<k-2;i++){
        ans += 'y';
    }
    ans += 'c';
    cout<<ans.size()<<endl;
    cout<<ans<<endl;
}
```
